### 本站由来

曦微博客是「曦微 XIVI」品牌下的个人技术博客。创立初衷是把日常折腾 AI 应用、Windows 桌面工具、自动化脚本与各类部署实践的过程沉淀下来，方便自己复盘，也方便有同样需求的人直接抄作业。

核心理念：**能自动化的绝不手动，能免费的绝不付费**。

### 架构概览

- **前端**：Next.js 16 App Router + React 19 + TypeScript + Tailwind CSS v4
- **部署**：Cloudflare Workers（经 OpenNext 适配层）
- **数据**：Cloudflare D1（SQLite）存储文章、用户、设置、评论、搜索日志、版本历史
- **存储**：封面与插图以内嵌 base64 data URI 形式存于 D1，无需图床
- **认证**：自建 HMAC 签名 Cookie 会话，不依赖 NextAuth
- **AI 封面**：浏览器直连 agnes 生成，规避 Worker 共享出口 IP 被限流

### 主要功能

#### 文章创作与编辑器

- **公共 Markdown 渲染器**：正文与预览共用同一渲染器，所见即所得，不存在「写了跟发出去不一样」。
- **分屏编辑**：工具栏 16 个动作（标题 / 加粗 / 列表 / 引用 / 代码 / 链接等）；写作区与预览区各自内滚、滚动同步。
- **图片上传**：编辑器内 `Ctrl+V` 粘贴或拖拽即传，`compressImage` 自动压缩后 base64 内嵌，无需图床、不限外链。
- **版本历史**：每篇最多保留 30 条，10 分钟窗口自动合并；编辑器右侧抽屉可随时回滚任意历史版本。
- **草稿与定时发布**：草稿状态自动保存并提示；可设 `datetime-local` 定时发布时间，到点惰性上线。
- **置顶**：单篇可置顶，列表优先展示在普通文章之前。
#### 分类与标签

- 以中文分类为主，每分类可设**英文别名**（如「免费AI资源」→ `free-ai-resources`），别名 URL 直接可访问，利于分享与 SEO。
- 标签页聚合同标签文章，支持别名访问。
#### AI 封面

- 接入 **agnes** 图像模型（agnes-image-2.0-flash），由**浏览器直连**生成，规避 Worker 共享出口 IP 被前置 Cloudflare 限流。
- 提示词为**标题海报式**，自动把文章标题渲染为画面唯一文字（模型一定会渲染文字，不写「无文字」）。
- 封面 635×360 中心裁切入库，并生成 240×135 缩略图供列表使用；后台支持**批量重跑全部文章封面**。
#### 推荐阅读

- 后台可将文章标记为「推荐」，全局**最多 5 篇**。
- 侧栏「推荐阅读」优先展示推荐文章；未设推荐时回落最新 5 篇。
#### 站内搜索与统计

- 全站搜索，过滤爬虫 UA；搜索词进入后台「访问统计」的**搜索词看板**，可观察用户真实检索意图。
- 搜索词与访问数据经匿名哈希，保护隐私。
#### 公告与友链

- **全站公告条**：可开关、带跳转链接，常用于活动或重要提示。
- **页脚友链**：后台可视化维护，一键增删。
#### 评论系统

- **免注册评论**：关于页与每篇文章底部均可留言。
- 同 IP 60 秒限频，防刷屏。
#### 后台管理

- 登录态基于 **HMAC-SHA256 + 会话 Cookie**（httpOnly，`xivi_session`），不依赖第三方鉴权。
- 模块：文章管理、标签管理、媒体库、访问统计、站点设置、数据备份、编辑器。
- **数据备份**：一键导出 / 导入文章 + 设置（不含版本历史）。
#### 多端适配

- 响应式布局：移动端页脚三竖列、分页单排显示、轮播完整呈现封面（`object-contain`）。
- 深色 / 浅色跟随系统。
